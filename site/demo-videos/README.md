# Genre demo videos

Put your recorded Ableton demos in this folder. The website automatically uses
these names, preferring MP4 over WebM:

| Landing frog | Filename |
| --- | --- |
| All styles (large center frog) | all.mp4 |
| Jazz | jazz.mp4 |
| Rock | rock.mp4 |
| Punk | punk.mp4 |
| Pop | pop.mp4 |
| Country | country.mp4 |
| Electronic | electronic.mp4 |

WebM is also supported with the same names, such as jazz.webm. Use an MP4 with
H.264 video and AAC audio for broad browser support. A 16:9 recording fits the
player; other aspect ratios are shown without cropping.

Optional English captions use the same name with a .vtt extension, such as
jazz.vtt. Each recording is loaded only when its frog is selected. Missing or
unplayable recordings fall back to a clearly labeled silent illustrated preview.

The dev preview notices new files automatically. Rebuild and republish the site
after adding or replacing videos for the hosted version.

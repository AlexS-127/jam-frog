# Jam Frog showcase site

The standalone, dependency-light Hacklanta project page lives here.

```sh
cd app
npm run site
```

Vite serves the site at `http://127.0.0.1:5173` (or the next port if that one is busy). The showcase is illustrative; it does not connect to Ableton or process MIDI.

The **Make a demo tape** button renders a silent 12-second walkthrough in the browser using the bundled sprite frames. When rendering finishes, visitors can play or download the video. No video service or app connection is required.

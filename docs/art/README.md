# Closing artwork

Put the final project drawing in this folder. Use jam-frog.png (or .jpg, .webp,
.avif, or .svg) to make it the preferred artwork. The website displays it at the
end of the page without cropping. If it has another filename, the first supported
image in alphabetical order is used.

Until an image exists, the artwork section stays hidden. The hosted site needs
to be rebuilt and republished after the drawing is added.
